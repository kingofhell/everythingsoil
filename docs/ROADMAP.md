# Everything Soil — Development Roadmap

## Guiding Rule

Build the smallest useful version first.

Do not implement future phases prematurely.

---

Goals:
- Confirm existing Django project structure
- Establish environment
- PostgreSQL
- Custom User model
- Base template
- Bootstrap 5
- Static/media handling
- Environment variables
- Development/production settings split
- Documentation

Deliverable:
A clean Django foundation.

# Definition of Done

A feature is not complete merely because code exists.

Before declaring a feature complete:

- Code implemented
- Migrations created
- Tests added
- Tests passing
- Django checks passing
- Permissions verified
- Mobile UI checked
- Error states handled
- Empty states handled
- Security considered
- Documentation updated
- No unrelated functionality broken

---

# Current Priority

If beginning from an existing Django project:

1. Inspect existing code.
2. Establish documentation.
3. Confirm settings/environment.
4. Implement custom User before other domain models.
5. Implement authentication.
6. Build the base design system.
7. Implement Phase 2 public content.
