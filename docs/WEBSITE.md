## 17. Design Direction

Visual character:
- Natural
- Calm
- Spacious
- Modern
- Earth-connected
- Authentic
- Minimal

Prefer actual photography from the farm and center over generic stock spiritual imagery.

Avoid:
- Excessive religious iconography
- Overcrowded pages
- Aggressive donation banners
- Fake mystical imagery
- Excessive animations

## 18. Mobile First

Primary traffic is expected to come from mobile/social sharing.

Ensure:
- Large touch targets
- Fast loading
- Simple navigation
- Responsive cards
- Compressed images
- Readable Tamil typography
- Sticky/mobile CTA where appropriate

## 19. SEO

Each important page needs:
- Unique title
- Meta description
- Canonical URL
- Open Graph metadata
- Structured headings
- Descriptive image alt text
- Internal links
- Breadcrumbs where appropriate

Content opportunities:
- Panja Bootham
- Five elements
- Soil
- Natural farming
- Meditation and nature
- Ecological knowledge
- Tamil traditional knowledge

## 20. Sharing

Public pages should have attractive social sharing metadata.

WhatsApp sharing is particularly important.

Shared links should have:
- Good title
- Short description
- Appropriate image
- Canonical URL
