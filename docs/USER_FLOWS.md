# Everything Soil — User Flows

## 1. Anonymous Visitor

```text
Visit Website
→ Home
→ Explore Soil / Panja Bootham
→ Read content
→ View Experience
→ View Event
→ Register
→ Google Sign-In
→ Complete Registration
```

Anonymous visitors should not be forced to sign in simply to read content.

## 2. New Member

```text
Google Sign-In
→ Create/complete Profile
→ Select Interests
→ Welcome
→ Explore Recommended Content
→ Join a Circle or Event
```

The profile setup should be short.

Ask only for information that is useful.

## 3. Event Registration

```text
Event Page
→ Register
→ Authenticate if necessary
→ Confirm participant information
→ Registration created
→ Confirmation page
→ Email/site notification
```

If payment is required:

```text
Event
→ Registration
→ Payment
→ Provider verification
→ Registration confirmed
```

Never mark a paid registration as successful based only on browser/client input.

## 4. Circle Membership

```text
Circle Page
→ Join Circle
→ Membership created
→ Button changes to Joined
→ User sees Circle in My Community
```

If a Circle requires approval:

```text
Join
→ Pending
→ Coordinator approves
→ Membership active
```

## 5. Practice

```text
Practice Page
→ Read instructions
→ Begin
→ Practice
→ Complete
→ Record completion
→ My Journey updated
```

Practices should not be competitive.

Avoid leaderboards.

## 6. Volunteer

```text
Volunteer Page
→ Explore Opportunities
→ Select Opportunity
→ Apply
→ Volunteer Profile if needed
→ Application submitted
→ Admin/coordinator review
→ Approved
→ Participation
→ Hours recorded
```

## 7. Story Submission

```text
Submit Story
→ Enter title/content
→ Upload image if desired
→ Submit
→ Status = Pending
→ Moderator review
→ Approved / Rejected
→ If approved, publish
```

## 8. Project Contribution

```text
Project Page
→ Understand purpose
→ See progress
→ Select amount
→ Payment
→ Server-side payment verification
→ Contribution recorded
→ Receipt
→ Project progress updated
```

## 9. Visit Request

```text
Visit
→ Select date
→ Number of people
→ Purpose
→ Notes
→ Submit
→ Pending
→ Center confirms
→ Confirmed visit
```

## 10. Personal Journey

```text
My Journey
├── Element practices
├── Events attended
├── Circles
├── Volunteer hours
├── Stories
└── Contributions
```

The Journey should be reflective rather than gamified.

## 11. Admin Event Workflow

```text
Create Event
→ Draft
→ Review
→ Publish
→ Registrations
→ Attendance
→ Feedback
→ Archive
```

## 12. Volunteer Workflow

```text
Create Opportunity
→ Publish
→ Applications
→ Review
→ Approve
→ Participation
→ Hours
→ Impact
```

## 13. Project Workflow

```text
Create Project
→ Define Goal
→ Publish
→ Contributions
→ Updates
→ Completion
→ Impact Report
```

## 14. Recommended Personalization

Use interests to recommend:
- Articles
- Events
- Circles
- Practices
- Volunteer opportunities

Do not send all users the same communication.

## 15. Core Product Loop

```text
Discover
→ Learn
→ Practice
→ Experience
→ Visit
→ Join
→ Participate
→ Contribute
→ Share
→ Discover
```
